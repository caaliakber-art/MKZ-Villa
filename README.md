# Jinad Residence: interactive 3D model

Open the live model: https://caaliakber-art.github.io/MKZ-Villa/

Bird's-eye, dollhouse and first-person walkthrough of the planned residence in Kodungallur (design by MAAD Concepts). Ground floor follows the architect's working drawing; the upper floor is indicative until the first floor plan is available.

Try: camera angles, walking up the stair, wall light switches, day/night and sun position, colour swatches, moving and adding furniture, the plan overlay and the measuring tool. Changes are saved in your own browser only.
